# VR-Tesst

Unity VR test project.

## Project Structure

- `Assets/` - project scenes, scripts, and art assets
- `Packages/` - Unity package manifest and lock file
- `ProjectSettings/` - Unity project configuration

## Git Notes

This repository is configured for Unity development. Generated folders such as `Library/`, `Logs/`, `Temp/`, and `UserSettings/` are ignored and should be regenerated locally by Unity.

Open this folder in Unity to restore generated files and package cache.
