# DeepSeaInvestigation_1VR 模拟器游玩手册

适用场景：`Assets/DeepSeaDemo/Scenes/DeepSeaInvestigation_1VR.unity`。

适用版本：当前工程的 Unity 6、XRI 3.3.1 **XR Interaction Simulator**。这不是旧版 XR Device Simulator 教程。下面按键来自工程内实际 `.inputactions` 和模拟器脚本；如果之后改了输入资产，以资产为准。

游戏内界面为英文，本文为中文。操作手册不代表所有流程已经完成头显实测；文末列出验收方法和已知限制。

## 1. 第一次启动：只做这几步

1. 退出 Play，打开上面的正式副本场景，不要打开原始 `1-VR` 或上一版 Demo。
2. 保存你自己的场景改动。不要运行 `Build Isolated Demo` 或重新装配整个场景。
3. 点击 Unity 顶部菜单：`Tools > Deep Sea Demo > Input > XR Simulator - Keyboard`。
4. 这个命令会启用场景里的模拟器、把 `DemoXRInput` 切成模拟器模式，不会自动保存。按 `Ctrl+S` 保存模式选择。
5. 等脚本编译完成，点击 Play，再点击 **Game** 窗口让键盘输入进入游戏。不要一直停留在 Scene 窗口操作。
6. 保持模拟器的设备类型为 **Controller**。不要切成裸手 Hand 模式测试摇杆。
7. 开局菜单需要用模拟手柄射线点击，不能把鼠标左键直接点击菜单当作 VR 交互。

切回真实 Quest：退出 Play，选择 `Tools > Deep Sea Demo > Input > Real VR - Quest Link`，保存，再进入 Play。不要同时开着模拟器和真实手柄测试。

`Desktop UI - Mouse` 是另一种模式，只方便用鼠标测试菜单，不是完整的 VR 模拟器流程。

## 2. 最重要的规则：Shift 才决定按键送给哪只手

**不按 Shift：T、G、IJKL 等控制右手。按住 Shift：这些输入送给左手。**

`[`、`]` 主要选择要移动/旋转的手部姿态，不等于把全部按钮输入永久切换到那只手。很多“左手没反应”是把这两种选择混淆了。

切换 Shift 前，先松开 T、G 和 IJKL，避免模拟器把上一只手留在按住状态。

### 常用按键表

| 操作 | 按键 | 说明 |
|---|---|---|
| 右手 Trigger | T | 菜单点击、持物使用、空手水下声纳 |
| 左手 Trigger | Shift + T | 同上，送给左手 |
| 右手 Grip | G | 抓取/放下；也可能是空手 QTE 判定 |
| 左手 Grip | Shift + G | 抓取/放下；右手持工具时用于 QTE |
| 左摇杆前后左右 | Shift + I / K / J / L | 正常角色移动，推荐用这组测试碰撞 |
| 右摇杆上/下 | I / K | 上潜、下潜；水面按 K 重新下潜 |
| 右摇杆左/右 | J / L | 转向，默认瞬转 |
| 左手 Menu | Shift + M | 游戏开始后暂停/恢复；Esc 也可测试暂停 |
| 主摇杆输入目标 | 9 | 若 IJKL 没反应，确认选择 Primary 2D Axis，别留在 0 对应的 Secondary Axis |
| 选择左手姿态 | [ | 用于移动/旋转左手模型的位置，不替代 Shift 按钮规则 |
| 选择右手姿态 | ] | 用于移动/旋转右手模型的位置 |
| 切换操纵设备 | Tab | 看模拟器提示当前选中哪台设备 |
| 切换头显姿态操纵 | H | 用于看向不同方向 |
| 旋转选中设备 | 按住鼠标右键并移动鼠标 | 或使用方向键进行旋转 |
| 平移选中设备 | W/A/S/D，Q/E | Q 向下、E 向上；这是模拟设备位姿，不是角色摇杆移动 |
| 重置模拟姿态 | R | 不是维修 QTE，也不是任务重试；正常流程尽量不用 |
| 切换快捷输入类型 | 反引号键（Esc 下方） | 在 Trigger、Grip 等快捷操作间循环，以模拟器显示为准 |
| 切换快捷操作按下状态 | Space | 会保持按下，再按一次才释放；适合维修时持续按 Trigger |

### 不要用 WASD 代替角色碰撞验收

模拟器默认 FPS 操纵会同时平移头显和两只手的追踪位置。它不等同于角色控制器移动，因此会影响身体与头的位置关系。检查“会不会卡门、沉底、上平台”时，请使用 **Shift + IJKL 模拟左摇杆**，而不是一直用 WASD 搬动头显。

同样，模拟器中的 Q/E 是追踪位姿升降。实际潜水逻辑用右摇杆 Y，即 **I/K**。旧教程里的“Q 下潜”属于独立桌面测试模式，不是这份模拟器教程的主控制方式。

## 3. 如何点开局菜单

1. 点击 Game 窗口。
2. 按 `]` 选择右手姿态，必要时按住鼠标右键转动右手，让射线指向 `New Game`。
3. 按一下 **T，然后松开**。按下/释放都要完成，按钮点击一般在释放时完成。
4. 菜单关闭、目标提示出现后，再用 **Shift + I** 向前走。

如果按钮不高亮：检查射线是否真的对准按钮、手是否在控制器模式、是否操作了另一只手。当前代码已补上 `DeepSeaUI` 射线层，原来的“射线排除了 UI”问题已修正。

在主菜单、阅读卡、暂停页中不能正常走动，是输入保护；先关闭面板或开始游戏。不要为了让菜单中也能走动再加一套移动脚本。

## 4. 从平台到下潜：按任务顺序走

### 4.1 整理装备与调查

开局位于你原有平台的装备房。按屏幕目标依次完成：

1. 找到第一份日志。空手射线对准日志，按右手 T 或左手 Shift+T。
2. 阅读后，用射线点击 `Close Record` 关闭阅读卡。
3. 到日志/监控区域，对准报警记录，执行 `Check Alarm Record`。
4. 回装备桌，拿起手电筒。
5. 对准装备站，执行 `Equip Suit`。当前穿戴交互要求先拿过手电筒。
6. 日志、报警核对、手电与潜水服条件齐全后，对准 `Begin Dive` 入水交互。

不是所有方块都要抓起来：日志、装备站、终端属于“射线 + Trigger”；手电、工具、石头和黑匣子属于“Grip 拿取”。

建议第一次按任务完整做一遍。直接从平台跳下去可以测试游泳/声纳，但不会自动补齐平台任务条件。

### 4.2 抓取手电筒

1. 用右手靠近手电，或在约 3 米内把射线对准它。
2. 按 G 抓取。远处物体会收回手边，使用固定握持点；当前近远交互器使用 Toggle 抓取：再按一次 G 放下。
3. 抓着时按 T 切换灯光开关。放下后可以保持亮着。
4. 左手操作对应 Shift+G 和 Shift+T。

摇杆只用于玩家移动、转向和升降，不再额外旋转或推拉手中的物品；甩手也不会放大远程抓取距离。

注意：不要在同一次操作中同时按住 Shift 改手、又松开 G。先完成一次按下/松开，再换另一只手操作。

### 4.3 游泳与漂浮

- Shift+I/K/J/L：水平移动，方向参考头部的水平朝向。
- I：上潜。
- K：下潜。
- 到达水面后进入漂浮状态，可以继续水平移动；按 K 重新下潜。
- 水下不输入升降时，角色逐渐下沉；接触海床后应停止继续下坠。
- 水面和水下均可抓取、使用手电、读取对应终端，不需要切换成另一套玩家。

## 5. 声纳、手电与投石

### 5.1 主动声纳

条件：游戏已开始、头部在水下、当前这只手空着、没有操作 UI/终端、没有维修 QTE、冷却结束。

最简单的测试组合：**右手拿手电，左手空着，按 Shift+T 发声纳。**

发波后松开，等约 1.5 秒再按一次。持续按住不会持续发射。

声纳现在是常驻手部能力，不再被“是否完成穿戴潜水服任务”隐藏锁住；任务进度仍需正常完成。

观察反馈：

- `SONAR PULSE SENT`：已经调用发射路径。观察附近物体的扫描显露和白描边。
- `Sonar recharging`：冷却中，松开后稍等再按。
- `Sonar works underwater only`：头部尚未被水体判为水下。
- 手上有东西：Trigger 交给该物品，换另一只空手发波。
- 指向日志/终端时：Trigger 优先进行该交互；将手移开目标再测试声纳。

不应看到常驻的“地球仪线框球”。完整线框球默认关闭不代表声纳坏了。水面网格不作为描边目标；水下脉冲也不应让建筑的水上部分发亮。

主动声纳会增加声学暴露并吸引敌人，不要把连续发波当成无限照明。远处没有可描边对象时，显示“已发射”也不保证眼前一定出现轮廓。

### 5.2 投掷石头

Grip 拿起石头，移动手后再次 Grip 放开，模拟投掷。碰撞声纳只对已配置的碰撞对象、速度和冷却条件生效；落到普通 Ground、轻碰或持续摩擦不应刷波。

模拟器不如真实手柄容易产生自然投掷速度。优先在近距离，用手部姿态平移产生速度后释放；“把静止石头放在地面”不是投掷测试。

投石的声源是碰撞点，可以引导敌人调查；不是把敌人持续锁定到玩家实时位置。

## 6. 维修工具与圆环 QTE

1. 在海床维修区域取得电子锁维修工具。
2. 到潜艇的实际舱门/锁位置，先把手电放到旁边的架子，腾出一只空手。
3. 右手 Grip 拿工具，让工具工作端靠近维修目标。
4. 持续按右手 Trigger（T），开始维修。
5. 圆环出现后，在成功区经过指针时，用另一只空手 Grip 判定。右手拿工具时，对应 **Shift+G**。
6. 成功继续维修；完美提供短时间加速；失败/超时会扣回维修进度。
7. 维修完成后，退开舱门开启区域，移走挡门的松散物体，等待舱门打开。

### 推荐的模拟器 QTE 操作：锁住右手 Trigger

两只手共享一套键盘，不建议一边换 Shift 一边随意松开 T。可以这样操作：

1. 选择右手姿态 `]`。
2. 用反引号键循环快捷输入，确认模拟器显示 **Trigger**。
3. 按 Space，让右手 Trigger 保持按下，工具持续维修。
4. QTE 来时，按一下 Shift+G，再松开 G 和 Shift。
5. 完成后仍选择右手、快捷输入仍是 Trigger，再按 Space 释放右手 Trigger。

如果你改了快捷输入类型，Space 操作的就不是 Trigger；务必看模拟器提示。模拟器模式下 **R 是重置姿态，不是 QTE 判定键**。

维修外观使用 Decal 随进度渐隐，失败扣进度时损坏会重新加重；不要求维修时替换模型。

## 7. 潜艇、黑匣子和结局

### 潜艇内

- 舱内完全进水，仍用游泳操作。
- 找到最后记录，用空手 Trigger 阅读并关闭。
- Grip 拿走黑匣子。当前可以是占位盒子，以交互名称和任务提示为准。
- 拿走黑匣子会触发备用电源/引擎相关剧情声，敌人可能调查舱外。
- 没有背包。手电、工具、黑匣子要通过双手和放置架安排，不能把“曾经拿过”当成物品已自动携带。

### 返回平台

1. 离开潜艇，沿返回灯标上浮。
2. 用 I 上潜，到水面保持漂浮。
3. 靠近平台的 `Board Platform` 交互，用任意一只手对准并按 Trigger；双手分别拿水样和黑匣子也能登乘，不需要先放下证据，两件物品会随玩家一起回到平台。
4. 登乘会进行安全位置检查；若提示目标受阻，先移开挡路物体，不要反复强行挤入平台。
5. 将黑匣子带到平台一楼解析工作台，设备已移到一楼，无需上二楼。

### 解析与选择结局

1. Grip 拿着黑匣子，将它移动到解析座的吸附位置。
2. 放开 Grip，让播放座接管物品。仅站在附近或指一下终端不等于已插入。
3. 等待记录/解析流程，阅读证据界面。
4. `Preserve Evidence / Refuse Upload`：保留证据结局。
5. `Upload to Company...`：进入上传确认，确认后进入另一结局。

水样、传感器和证词属于补充证据；缺少可选证据仍可完成黑匣子主线。实体水样要带回对应接收座，文档/传感器读取后登记事实。

上传结局中的“删除资料”只是假想剧情，不删除真实工程文件。

## 8. 暂停、重试与常见问题

| 现象 | 优先检查 |
|---|---|
| 进 Play 没有模拟器 | 是否在退出 Play 后选了 `XR Simulator - Keyboard`；DemoXRInput 是否仍是 RealVR |
| 菜单点不了 | Game 是否有焦点；Controller 模式；右手 T/左手 Shift+T；射线是否指向按钮 |
| WASD 能移动但摇杆不走 | WASD 可能在搬动追踪设备；用 Shift+IJKL，并确认按 9 选择主摇杆 |
| 主菜单中不能走 | 正常，先点 New Game；阅读/暂停界面也会锁定移动 |
| 水下按 T 没声纳 | 默认是右手；右手持物就用 Shift+T；头部需要在水下 |
| 显示已发波但没轮廓 | 观察附近目标；若仍没有，记录此现象，区分输入成功与渲染失败 |
| 修理时按 R 没用 | 模拟器 R 是重置姿态；用另一只空手的 Grip |
| 工具/Trigger 好像一直按着 | Space 快捷输入可能锁住了按钮；回到相同手和相同快捷类型，再按 Space 释放 |
| 门修好了却不打开 | 玩家、手持物或松散物体可能挡住安全开启区域，向后退开 |
| 卡住或掉到异常位置 | 打开暂停页，选 Return to Safe Position；不要拖 Scene 中的 Player 当正常操作 |
| 想重新测试本章节 | 暂停页 `Retry Chapter Checkpoint` |
| 退出后继续 | 下次主菜单 `Continue Checkpoint`；不要把 New Game 当继续 |

装备房门口本轮只调整针对门洞的碰撞，不会把整个平台关闭碰撞，也不会提高全局跨步高度让玩家翻过栏杆。门槛模型外观可以保留，但不应再成为角色通行的高台阶。

## 9. 建议按这个顺序验收

先做短测试，不要每次都玩到结尾才发现输入出错：

1. 开始菜单能悬停和点击，New Game 后左摇杆模拟能走。
2. 空手能出装备房门口，来回通过；手上拿工具再测一次。
3. 右手拿手电，T 能开关；左手 Shift+T 不抢用手电。
4. 下水后左手 Shift+T 发一波，确认没有整个画面闪烁或大幅卡顿。
5. 深处发波，水面网格和平台水上建筑不应出现声纳描边。
6. 工具维修和另一只手 QTE 能完成。
7. 真正拿到并带回黑匣子，插入解析座，进入一个结局。
8. 再测试章节重试与继续存档，确保没有复制关键物品。

若出现强烈闪烁，先退出 Play，不要连续发波。定位文件：

- `Logs/DeepSeaDemo/Sonar-Input.txt`：每次 Trigger 被接受或拒绝的原因。
- `Logs/DeepSeaDemo/Sonar-Render.txt`：实际脉冲、描边数量、CPU 帧间隔和前若干个运行报错。
- `Logs/DeepSeaDemo/XR-PlayerInput.txt`：开局约一分钟的真实玩法输入读数。
- `Logs/DeepSeaDemo/Doorway-Repair.txt`：门口碰撞检查记录。

这些是诊断记录，不是 Quest 双眼效果或 72 Hz 性能已经通过的证明。模拟器流程跑通之后，仍要单独测试真实手柄、左右眼、舒适性和性能。
