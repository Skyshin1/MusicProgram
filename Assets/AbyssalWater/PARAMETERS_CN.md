# Abyssal Water 参数速查

## 从哪里调

打开示例场景后，选中 Project 中的
`Assets/AbyssalWater/Samples/AbyssalWater_PC_VR_High.asset`。
默认是 **Simple** 面板；展开 **Advanced — 完整可定制参数** 可看到全部控制。

场景中 `Abyssal Water System` 只放引用、海平面和诊断开关；视觉参数都集中在 Profile，
避免同时改材质、Volume 和多个脚本。

## Simple 常用参数

| 参数 | 作用 |
| --- | --- |
| 波浪高度 | 整个生成波谱共享的总振幅预算，不会随频段数量失控叠加 |
| 波浪尺度 | 同时缩放全部波长；越大越像长涌浪 |
| 波浪速度 | 全波谱时间倍率 |
| 主风向 / 风速 | 主传播方向和色散速度 |
| 浪尖陡峭度 | Gerstner 水平位移强度；过高会形成尖浪 |
| 算法去重复 | 总开关；同时控制波谱连续相位扰动与法线贴图随机旋转混合 |
| 表面微波细节 | 0 为关闭；增大后水面高频起伏和焦散细胞更丰富 |
| 水体透射颜色 | 指定参考距离后剩余的 RGB 光能 |
| 透射颜色参考距离 | 把颜色换算为吸收系数时使用的米数 |
| 反射强度 | Fresnel 环境／平面反射倍率 |
| 物理焦散强度 | 折射光线面积聚焦的能量倍率 |
| 泡沫强度 | 波峰、岸边和动态接触泡沫的总倍率 |
| 水下吸收/雾倍率 | Beer–Lambert 光程的整体倍率 |

## Advanced 主要分组

- **波谱与曲线**：频段数、最短/最长波长、方向离散、随机种子、
  `波长 → 振幅` 与 `波长 → 方向离散` 两条曲线，以及最多 12 条手动波。
- **算法去重复**：连续相位扰动会弯曲有限波谱的等相位线，随机旋转混合会把法线贴图
  拆成无缝随机单元；两者共享一个总开关，但可分别把强度设为 0。相位空间尺度越大，
  变化越缓；过小会让长涌浪显得破碎。
- **光学微波谱**：最多 8 条对数分布、多方向短波，参与表面法线和真实光线焦散，
  不加入浮力高度，避免高频视觉细节让物理物体抖动。方向离散建议海面使用 110°–170°。
- **Beer–Lambert 与体积散射**：散射颜色/强度、各向异性 `g`、最大水中光程。
  Inspector 会实时显示由透射颜色换算出的线性吸收系数 `σa`。
- **反射、折射与浪尖透光**：IOR、屏幕折射、光滑度、法线强度、
  逆光浪尖透射颜色和聚焦指数。
- **泡沫与弯月面**：波峰阈值/羽化、岸边距离、动态接触泡沫、物体接触弯月面宽度。
- **真实波面焦散**：宏观波与微波的联合曲率、光程/曲率尺度、折射光线面积聚焦、
  RGB 色散和最大深度。微波会随水深自动过滤，减少远处闪烁。
- **吃水线与水下**：水下折射扰动、吃水线厚度/亮度、水下光束开关与强度。
- **Dynamic Waves**：覆盖范围、分辨率、传播速度、衰减、扰动高度、子步数和每步扰动源上限。
- **无限海洋 LOD**：LOD 环数、每环网格密度、中心环尺寸和远端裙边。

## 场景级设置

选中 Hierarchy 的 `Abyssal Water System`：

- `Water Level`：水面世界高度，会跟随该对象的 Y。
- `Viewer`：无限海洋与 Dynamic Waves 跟随的相机/玩家。
- `Show LOD Bounds`：只在 Scene 视图显示 LOD 轮廓。
- `Show Dynamic Wave Area`：只在 Scene 视图显示近场模拟范围。

主相机上的 `Abyssal Planar Reflection` 控制反射分辨率、最大尺寸、裁剪偏移、
更新间隔、最远距离、阴影和粗糙度 Mip。默认使用 Profile 的 PCVR/VR/Quest 预算，
投影纹理边缘会自动羽化，不再显示相机矩形硬边。

## 去重复推荐值

| 场景 | 相位扰动强度 | 相位空间尺度 | 随机法线混合 | 微波数量 / 振幅 |
| --- | ---: | ---: | ---: | ---: |
| PCVR 写实海面 | 0.5–0.9 | 40–80 m | 0.8–1.0 | 8 / 0.04–0.08 m |
| VR Balanced | 0.35–0.7 | 50–100 m | 0.35–0.65 | 5 / 0.03–0.06 m |
| Quest | 0.25–0.5 | 70–140 m | 0（节省纹理采样） | 3 / 0.02–0.04 m |

## 示例快捷键

- `1`：水上，查看平面反射、折射、浪尖透光和泡沫。
- `2`：吃水线，查看水上/水下双向过渡。
- `3`：水下，查看指数吸收、散射、真实波面焦散和水下光束。
- `Space`：在相机附近注入一次大型 Dynamic Wave 扰动。

玩家、鱼、潜艇或刚体添加 `AbyssalWaterInteractor` 后，会按半径、强度、速度和入水深度
自动产生传播波；需要浮力的物体再添加 `AbyssalBuoyancy`。
